# Overview

Leginon is a system designed for automated collection of images from a transmission electron microscope.

## Contact information:

Leginon issue tracking and repository are hosted [on github](https://github.com/leginon-org/leginon).

Use the [issues tracker](https://github.com/leginon-org/leginon/issues) to report bugs and request features.
