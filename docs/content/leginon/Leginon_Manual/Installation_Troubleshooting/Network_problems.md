## Microscope host that runs Leginon client does not appear in the Launcher list on the Leginon processing computer

***Possible reasons:***

-   Host files are not configured properly so that the computers can not commnuicate
    by specifying the hostname.


-   Connection is refused by one of the computers involved. This might be caused by a
    firewall or a inactive server.

***Testing and Solutions:***

-   [Test network connection](/leginon/Test_Network_Connection_Between_Remote_and_Microscope_Computers) with test scripts
    test1.py and test2.py as described in the "Start Leginon" chapter. Various solutions
    are listed in the same section.

For more discussion, see the Leginon forum [thread on network problems](http://emg.nysbc.org/redmine/boards/6/topics/3) .
