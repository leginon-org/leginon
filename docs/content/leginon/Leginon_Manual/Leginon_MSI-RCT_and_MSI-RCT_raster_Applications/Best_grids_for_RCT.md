Ideal grid for automated RCT acquisition: grid with distinct feature at more than one scale level.

For example, thin-carbon over C-flat MH series grids and grid with some fiducial.

## Our favorite grid for RCT

C-flat **CF-2/0.5-4C-T**. Thin carbon floated on it so that we image over the thin carbon area.

The 3x3 pattern makes each of these patches more unique upon distortion of feature at different tilts. See [RCT node set-up](/leginon/Leginon_Manual/Leginon_MSI-RCT_and_MSI-RCT_raster_Applications/RCT_node_set-up) for examples of it at different tilts.
