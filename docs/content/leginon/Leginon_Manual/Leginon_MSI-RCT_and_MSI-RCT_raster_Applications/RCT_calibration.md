RCT type of data collection need the normal MSI calibration. In addition, the followings are also required.

-   image shift matrix and stage or modeled-stage calibration at the 1700x preset used for selecting RCT targets
-   recently saved rotation center in the database (You can do so in "Beam Tilt" node in "Calibration" application.
