Applications are workflows of tasks performed by individual instances of node class. You can create your own applications but the ones come with the distribution is a good set. You will more likely want to edit the applications to add new function that becomes available in a newer version.

The other common reason for editing applications is to make a new application where the node has a different name

Leginon settings are defined by the node class and the instance name (called node alias in Application Editor), not by application. Therefore, you can setup your presets in "Presets Manager" node of Calibrations application and then close that and get the same presets in "Presets Manager" node of MSI-T application. When you run Leginon on different scopes with the same database, giving application an identity to the scope with certain node name changed will help its settings separate among different scopes and camera. This way you don't have to change settings every time you switch scopes.
