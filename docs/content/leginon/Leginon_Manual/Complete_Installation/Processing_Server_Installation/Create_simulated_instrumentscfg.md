Due to a bug in Leginon #1311, instruments.cfg is required on processing host for Leginon even though the real instruments it uses are not on there.

## Copy the template file to be used as instruments.cfg

You can use the host-wide myami installation folder, or the installation directory similar to [leginon.cfg locations](/leginon/Leginon_Manual/Complete_Installation/Processing_Server_Installation/Configure_leginoncfg)

    cd where_you_want_to_keep_instruments.cfg
    cp your_myami_download/pyscope/instruments.cfg.template instruments.cfg
