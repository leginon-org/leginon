fei.cfg replaces various constants set inside the old tecnai.py that some local installation tend to change. The separate cfg file allows easier update to future releases.

* A template for fei.cfg is in the installed pyscope directory as "fei.cfg.template". Copy it to


C:\Programs File (x86)\myami\fei.cfg


The template file is configured with the default behavior. No change is required normally.

If you are upgrading and have changed tecnai.py, please make the corresponding changes in fei.cfg. If you do not find the option, please let Leginon development team know.
