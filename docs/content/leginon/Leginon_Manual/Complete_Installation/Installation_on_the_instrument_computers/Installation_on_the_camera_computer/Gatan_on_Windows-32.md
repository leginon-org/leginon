## Option 1

If the camera does not come with a PC separate from your FEI computer,
use [tecnaiccd.dll come with Tecnai, and other newer TEMs from FEI](/leginon/Leginon_Manual/Complete_Installation/Installation_on_the_instrument_computers/Installation_on_the_camera_computer/Gatan_on_Windows-32/Gatan_on_Windows-32_with_TecnaiCCDdll).

## Option 2

If you have already installed SerialEM or if the camera computer is separated from the scope computer, SEMCCD.dll created by SerialEM developer can be used instead of tecnaiccd.dll.

See [Gatan on Windows with semccd.dll](/leginon/Gatan_on_Windows-32_with_semccddll)
