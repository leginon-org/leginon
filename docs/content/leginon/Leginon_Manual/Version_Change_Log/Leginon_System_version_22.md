Version 2.2 contains refinement of previously available features and some bug fixes. Biggest new feature is multiple retractable camera support on the same scope and basic support for Direct Electron DE12 camera that is capable of saving raw frames of a movie series in sync with the integrated image of the same sent to Leginon.
