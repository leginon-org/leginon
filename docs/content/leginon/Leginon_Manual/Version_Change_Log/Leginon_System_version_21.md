Version 2.1 contains refinement of previously available features and some bug fixes. Most importantly, we found that certain TEM scripting version gives beam tilt value in unit other than radians. We encourage all Leginon users to [the script provided with the new pyscope to check the scaling on the scopes](/leginon/Leginon_Manual/Instrument_Set-up/Calibrations_required_on_FEI_microscopes/TEM_Scripting_Beam_Tilt_Calibration) to ensure proper performance.
