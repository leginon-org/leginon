**This list is updated with each release of 2.0.x**

-   Problem of finding gain references for Manual Acquisition is fixed by the new method of finding references in the database and memory (2.0.0)


-   Problem of resuming image acquisition from Square Targeting after Leginon restart may cause reacquisition of children of the unfinished target list on 32-bit Linux machine is solved. (2.0.0)


-   Verify that Correction Plan for bad pixels/column/row is not out of bound (2.0.2)
