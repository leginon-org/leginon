## Display of resolution ring in the power spectrum

-   Activate/Disable by scale-bar tool

## Option for display power spectrum

-   Either by binning down the image after calculating the power spectrum which shows the spectrum to full reciprocal spacing but sampled more roughly in frequency space (original), or by binning down the image before calculating the power spectrum which creates a zooming effect so that information at lower reciprocal spacing is better resolved (new default).
