## Film Exposure

* Use exposure wait time assigned in TUI to delay exposure after the film plate is inserted.

* Improve information printing on the film

## DTFinder

-   Fit a user drawn ellipse to define the geometric center as target

## FFTMaker

-   Crop rectangular image to square before Fourier Transform.

## Navigator

-   Tools for reset stage (x,y), z, and alpha

## PresetsManager

-   option to add additional pause time defined for cycling between image acquisition and preset change during preset image shift alignment

## RasterTargetFilter

* Limit the raster shape with rectangle as a new option. Press down shift key and choose two adjacent corners when using the ellipse fitting tool

## TargetFilter

-   Allow removal of manual removing of the targets after automated filtering

## TargetRepeater, Acquisition

-   Option for reset the stage after the node finishes processing the target list added.

## TestTargetFinder (New node class)

* An example TargetFinder for Leginon developer who wants to incorporate python function that output target coordinates from input numpy image array.
