The Leginon "MSI T" application uses JAHC Finder (Template Hole Finder) nodes to perform automated hole finding. This hole finder uses a template image of the the hole for correlation. Users should read [Multi-Scale Imaging Applications in General](/leginon/Leginon_Manual/Multi-Scale_Imaging_Applications_in_General) chapter and consult this chapter when it comes to Hole Targeting and Exposure Targeting. We have the plan to consolidate the hole finders into one, but not in this version, yet.
