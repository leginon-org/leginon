For it to work properly, you must select "Wait for a node to finish" under Exposure node, otherwise it will try to do measurements while moving on to the next image.
If you turn it off, you must deselect this or Leginon will get "stuck" at the exposure node. Leginon will warn you if there is a problem with settings

Results will appear in the Summary Page under "Zero Loss Peak Ice Thickness". They can be downloaded if a particular plot is desired.
