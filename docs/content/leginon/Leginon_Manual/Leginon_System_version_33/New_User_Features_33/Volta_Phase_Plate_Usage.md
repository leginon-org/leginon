Automated control of holeless Volta phase plate from FEI is not available as a external scripting call. Ways around this lack of feature has been developed using simulated mouse manipulation scripting from AutoIt, thanks to Wim Hagen. There are a number of workflow modification to achieve automated single-particle imaging that involves patch position advancing at user-defined number of exposures, charging the phase plate to a stable phase shift value, and multiple target beam-tilt focusing.
