[Grid management shared](/leginon/Grid_management_shared)

You may register grid boxes and grids by projects. This is mainly used with grid handling
robot.

-   Click on Grid Tray


-   Add a new box under the heading "Grid Boxes". You can choose from one of the three
    existing format.


-   Add a new grid by clicking on new under the heading "Grids".


-   After the name and other optional information are added, click on "Add". This will
    add the grid box selection below the form.


-   Click on the location where the grid is to be placed, the page is updated and the
    page reloaded. Important: Do not click on "update" because it will remove your last
    location selection. Use the side-bar to go to "Grid Tray" page.
