Seven MSI applications are distributed with Leginon.

-   [MSI-Edge](/leginon/Leginon_Manual/Leginon_MSI-Edge_Application/Summary_of_this_application) (Previously known as MSI)


-   [MSI-T](/leginon/Leginon_Manual/Leginon_MSI-T_Application/Summary_of_this_application_-_MSI-T) (T stands for template) (This one performs better than MSI-Edge in general)


-   [MSI-Raster](/leginon/Leginon_Manual/Leginon_MSI-raster_Application/Summary_of_this_application_-_MSI-raster)


-   [MSI-Tomography](/leginon/Leginon_Manual/Leginon_MSI-Tomography_Application)


-   [MSI-RCT](/leginon/Leginon_Manual/Leginon_MSI-RCT_and_MSI-RCT_raster_Applications/Summary_of_this_application_-_MSI-RCT) (For random conical or orthogonal tilt image
    collection)


-   [RobotMSI-Section](/leginon/Leginon_Manual/Leginon_RobotMSI-Section_Application) and MSI-Section3step (Simplified MSI for
    low-mag tissue section imaging)


-   [RobotMSI-Screen applications](/leginon/Leginon_Manual/Leginon_Robot-MSI-Screen_Applications/Summary_of_this_application_-_Robot-MSI-Screen) (For crystal screening, not
    working without a grid-loading robot)

MSI-Edge, MSI-T, and MSI-Raster each uses a different automated target finders in
Hole(Subsquare) Targeting and Exposure Targeting.

-   In addition, There are variation of the applications that are modified so that they can be run on [a system where the microscope and camera are controlled by different computers](/leginon/Using_Leginon_on_a_system_where_the_microscope_and_camera_are_controlled_by_different_computers). These are tagged with the number "2" at the end of the application name.
