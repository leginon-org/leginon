You can replace the RasterFinder class used in MSI-Raster Application "Exposure Targeting" node with RasterFCFinder class to use this.

See [Use the Application Editor to create Leginon applications](/leginon/Leginon_Manual/Create_and_Edit_Applications/Use_the_Application_Editor_to_create_Leginon_applications) under the section on **Use a different node class for an existing node alias**

The node you want to edit is "Exposure Targeting".
Replace RasterFinder class with RasterFCFinder. You can use the same alias name.
Save as a different application name
