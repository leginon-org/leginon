## Short Manual (Basic Leginon User) - Getting Started

These steps are intended to help the basic Leginon user who will operate Leginon (and
not care about installation or the first-time calibrations).

To use the recommended new wiki version, start at [Getting Started as a basic Leginon user](/leginon/Leginon_Manual/An_Introduction_to_Leginon/Getting_Started/Getting_Started_as_a_basic_Leginon_user)

To print out the old-style manual, download [part I](http://emg.nysbc.org/software/leginon/pdf/ShortManual1.pdf) and [part II](http://emg.nysbc.org/software/leginon/pdf/ShortManual2.pdf)
