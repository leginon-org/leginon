Multi-grid autoscreening uses autoscreen.py to go through MSI workflow on each grid. This is applicable to any MSI application but is not compatible with Queuing, yet.
MSI-Ptolemy application descripted here calls Ptolemy through shell script and receives output in json format. Developers can substitute their own program for it.
