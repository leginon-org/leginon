The Grigorieff lab at Brandies provides several individual programs that are used in Appion. See their [main software page](http://emlab.rose2.brandeis.edu/software) to download their software

## Software used in Appion:

-   [Frealign](http://grigoriefflab.janelia.org/frealign) --- Refinement of 3D reconstructions using single-particle images
-   [CTFfind and CTFtilt](http://grigoriefflab.janelia.org/ctf) --- CTF estimation
    -   **NOTE:** Once installed, you must rename version 4 of ctffind to ctffind4 and ctftilt.exe to ctftilt64.exe or create symbolic links. Otherwise, you will receive an error that ctffind4 was not found during ctf estimation.
