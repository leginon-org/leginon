Appion-Protomo is a semi-automated implementation of Protomo 2.4.1, with the option of fully automated batch tilt-series processing.

The Docker Appion-Protomo github page includes a tutorial and complete example: https://github.com/nysbc/appion-protomo

For a technical overview of Protomo and for diagnosing Protomo-specific issues, refer to the Protomo User's Guide: http://www.electrontomography.org/?page_id=317
