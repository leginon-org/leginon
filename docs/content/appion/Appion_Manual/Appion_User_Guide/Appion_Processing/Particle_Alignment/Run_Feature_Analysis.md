Feature analysis refers to systematic techniques for extracting features from a series of [aligned particles](/appion/Appion_Manual/Appion_User_Guide/Appion_Processing/Particle_Alignment/Run_Alignment) with the intent of clustering images with with similar features together. Feature anaylsis is closely related to multivariate statistics . All of these feature analysis techniques fall into two categories: principal component analysis (PCA) (Spider Coran and IMAGIC MSA) and neural networks (Xmipp KerDen SOM).
