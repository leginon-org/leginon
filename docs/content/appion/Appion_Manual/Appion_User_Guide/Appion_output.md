## Viewing Appion Results

-   Many of the results of the output can be viewed using the Leginon viewer of the given experiment. These include the picked particles and the ACE outputs.


-   Many of the results can be seen on the Leginon summary pages for the given experiment. These include statistics on the particle picking and ACE run.


-   On the Appion web user interface, clicking on any of the "completed", or "available" links will direct the user to a new page summarizing the results of the particular run and with further links to the details of the run.
