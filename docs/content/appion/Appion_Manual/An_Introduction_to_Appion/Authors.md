## Software packages

[From the EM community]{.underline}

Appion exists to provide an integrated interface to the following Image Processing software packages:

-   [Chimera](http://www.cgl.ucsf.edu/chimera/)
-   [EMAN](http://blake.bcm.tmc.edu/eman/)
-   [Grigorieff lab software](http://emlab.rose2.brandeis.edu/software)
-   [IMAGIC](http://www.imagescience.de/welcome2.htm)
-   [Imod](http://bio3d.colorado.edu/imod/)
-   [Protomo](http://www.electrontomography.org/software.html)
-   [SPIDER](http://www.wadsworth.org/spider_doc/spider/docs/spider.html)
-   [Xmipp](http://xmipp.cnb.csic.es/)

[Appion also depends on several community supported Open Source packages, including:]{.underline}

-   [ImageMagick](http://www.imagemagick.org)
-   [MySQL](http://mysql.com)
-   [NumPy](http://numpy.scipy.org/)
-   [PHP](http://www.php.net)
-   [Python](http://www.python.org)
-   [SciPy](http://www.scipy.org)
