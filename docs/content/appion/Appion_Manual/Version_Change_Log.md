## Current release

-   Appion Version 3.4 Road map


-   This version updates packages used in frame-alignment, ctf estimation, and particle picking, and stack making. These are regularly used and should be robust.
-   We do not have the user and developer force to keep 3D reconstruction of the pipeline up to date any more. The use of these is no longer supported.*

### Major function added

-   MotionCor2 frame alignment handles LZW compressed TIFF movies automatically.
-   Better CTF summary report including diagnosis plots that helps monitoring effect of lens aberration correction.
-   Image Rejector that rejects images with crystalline ice.
