Appion Version 3.0 includes the following changes:

1.  CentOS 6 compatible - there are major changes to the web server and processing server to be compatible with newer versions of PHP and Python.
2.  New features for Director Detector images including [Frame Alignment](/appion/Appion_Manual/Appion_User_Guide/Appion_Processing/Direct_Detector_Frame_Processing)
3.  Added an automatic masking tool called EM Hole Finder. The EM Hole Finder software computes masks of carbon holes in electron micrographs and is available at https://github.com/hbradlow/em_hole_finder.
4.  Improved CTF reporting tools.
5.  Added SIMPLE abinitio alignment and reconstruction
6.  Added Support for GPU version of FindEM
7.  Added support for the [Maskiton](/appion/Appion_Manual/Appion_User_Guide/Appion_Processing/Region_Mask_Creation/Maskiton) image masking tool
